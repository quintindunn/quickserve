## WIP: QuickServe
**QuickServe** is a cross-platform, modular, and intuitive application for creating servers for all different games. Simply drag & drop the module for your game, and with 1 click, create a server for it.

## NOTE (IMPORTANT):
QuickServe is still in heavy development; many features are lacking in terms of documentation, implementations, testing, and more. Currently, the only module in development is a module for [Vanilla Minecraft](https://www.minecraft.net/en-us). This will change as the project progresses; check out [Official Modules](#Official-Modules)

## Features:
- Simple drag-and-drop installation for modules.
- Shared and automatic runtime installations.
- Built-in file browsing, editing, deleting, and creating.
- Create your own modules using an easy API.
- **WIP**: Automatic port forwarding for the NightHawkRax70 router (and more in the future)\!

## Limitations:
While writing this project, I have only been able to test on Ubuntu 26.04 and macOS 26.5.2. Subsequently, Windows has not been fully implemented and hasn't been tested.

### Known Windows Issues:
- JRE Installation will throw a NotImplementedError
