# QuickServe

### NOTE (IMPORTANT):

QuickServe is still in heavy development, many features are lacking documentation, implementations, testing, and more. Currently, the only module in development is a module for [Vanilla Minecraft](https://www.minecraft.net/en-us). This will change as the project progresses.

### Features:

* Simple drag-and-drop installation for modules.
* Shared and automatic runtime installations.
* Built in file browsing, editing, deleting, and creating.
* Create your own modules using an easy API.
* **WIP**: Automatic port forwarding for the NightHawkRax70 router (and more in the future)!

### Limitations:

While writing this project, I have only been able to test on Ubuntu 26.04, and MacOS. Windows has subsequently not been fully implemented, and has not been tested.

#### Known Windows Issues:

* JRE Installation will throw a NotImplementedError
