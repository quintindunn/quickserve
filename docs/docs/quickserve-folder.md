# QuickServe Folder

### How to find your QuickServe folder.

The location of the QuickServe folder depends on the machine that is running QuickServe's operating system.

Here is a breakdown of folder locations depending on operating system:

| Operating System | Location                |
| ---------------- | ----------------------- |
| Windows          | Not yet supported       |
| MacOS            | /opt/quickserve/modules |
| Linux            | /opt/quickserve/modules |

for future reference, this will be called `QS-FOLDER` in the rest of the documentation.
