# Modules

### What are Modules?

Modules add the ability to install the software for server creation only for the games you want to play. There are both official modules, and community made modules.

#### Official Modules

Official modules are managed by the QuickServe team (as of 09/27/2026, that's just me). Any bugs, features, or questions related to them can be asked as an Issue on the official GitHub repository for QuickServe, https://github.com/quintindunn/quickserve.

#### Community Modules

Community modules are managed by individual members of the community, Any bugs, features, or questions should be directed to the author of the module. This can be found on the `about` page of the module.

In the future, there will be a centralized repository containing verified community modules.

**Note: Modules are NOT in a sandboxed environment, they have the same permissions as the QuickServe process. Only install trusted modules, and verify they aren't malicious**

### Module Installation

The module system was designed to be as simple as possible to install. Simply download the module and drag it into the modules directory of QuickServe.

The modules folder is located at `<QS-FOLDER>/modules` . See [QuickServe Folder](quickserve-folder.md) to find you `<QS-FOLDER>` .
