# Contributing to QuickServe

There are two main ways to contribute to QuickServe, and both are greatly appreciated

### Contribution Guidelines

To make the project easy to contribute to, QuickServe must remain consistent with its structure, naming conventions, and documentation. A guide to the contribution guidelines can be found on the [Contribution Guidelines](contribution-guidelines.md) page.

### Contributing to the core project

The QuickServe core constantly gets questions, bugs, new feature requests, and falls behind on tests, and you can help with any of these! Find an issue that you want to work on [here](https://github.com/quintindunn/quickserve/issues), fork the repository, and push your changes. When you're done, make a pull request on [GitHub](https://github.com/quintindunn/quickserve).

### Contributing by making a module

QuickServe can only support as many games as the community can provide. You can help create a module for any game that supports creating dedicated servers!
